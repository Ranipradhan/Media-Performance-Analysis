# Media Performance Analysis Dashboard

## Project Overview
This project analyzes sample media article data using Microsoft Excel and SQL to understand content performance and audience engagement.

## Tools Used
- Microsoft Excel
- SQL (MySQL 8.0)

## Dataset
The dataset contains 15 sample media articles across four categories:
- Technology
- Business
- Entertainment
- Sports

## Key Analysis
- Total views and clicks
- Average Click-Through Rate (CTR)
- Category-wise views and clicks
- Highest- and lowest-viewed articles
- Likes, shares, and total engagement
- Average CTR by category

## Excel Dashboard
Created an Excel dashboard using formulas, KPI summaries, and charts to compare category performance and communicate key findings.

## SQL Skills Demonstrated
- SELECT statements
- Aggregate functions such as SUM and AVG
- GROUP BY and ORDER BY
- Category-wise analysis
- CTR calculations

## Key Findings
- Entertainment received the highest total views in the sample dataset.
- Sports ranked second in total views.
- Business received the lowest total views among the four categories.

## Project Files
- `Media_Performance_Analysis.xlsx` — Excel data, analysis, and dashboard.
- `Media_Performance_Analysis.sql` — SQL queries used for analysis.

**Note:** This project uses sample data for learning and demonstration purposes.
